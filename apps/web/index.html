TRUST & DATA HANDLING

Evidence you can inspect.
Boundaries you can explain.

AgentGuard is designed for agencies that need a reproducible answer before a storefront agent touches a refund, cancellation, ticket, or customer record.

01

What is stored

Scan metadata, scenario outcomes, proposed tool names and arguments, policy decisions, safety signals, timestamps, and audit events. Evidence is workspace-scoped and exportable on eligible plans.

02

What is protected

Endpoint URLs and API keys are encrypted at rest; the dashboard receives only the endpoint host. AgentGuard sends synthetic test inputs and does not request customer data for the public lab.

03

Retention you can see

Evidence retention follows the plan: 7 days on Explorer, 30 on Builder, 90 on Pro, and 180 on Agency. An automated worker purges expired scan evidence; deleting a workspace removes its records.

04

Endpoint contract

Connect a JSON HTTP endpoint that accepts POST requests and an optional Bearer API key, then returns assistant_text or text plus optional tool_calls. Production requires HTTPS; use a mock or staging executor for scans.

COMMON QUESTIONS

Security clarity for
the people shipping agents.

What does AI agent security testing check?+

AgentGuard checks whether an agent can be manipulated into unsafe tool calls, privilege escalation, cross-tenant access, data exfiltration, prompt injection, and business-policy bypasses.

Does AgentGuard test a real customer endpoint?+

It can call the configured HTTP endpoint with isolated synthetic scenarios and record the response and proposed tool_calls. AgentGuard does not execute those tools itself, but an endpoint can still execute internally; that is why Production scans are blocked by default and a mock or Staging executor is required.

Why does the public lab show 3 challenges while the dashboard says 12?+

The public Attack Lab is a no-login, synthetic proof with three focused challenges: policy limits, approval tampering, and replay defense. The authenticated dashboard unlocks the full 12-scenario red-team suite according to the selected plan.

What happens after an unsafe behavior is found?+

You get the evidence and a plain-language recommendation. An owner or admin can review the generated plan and enable the Runtime Firewall; business policy values are never changed silently.
